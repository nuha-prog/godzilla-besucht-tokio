Godzilla besucht Tokyo
 Projektbeschreibung :
In diesem Photoshop-Projekt wird Godzilla in eine Szene von Tokyo integriert. Dabei werden verschiedene Bildelemente miteinander kombiniert, sodass eine möglichst realistische und harmonische Gesamtkomposition entsteht.
Neben Godzilla werden mindestens vier weitere frei gewählte Elemente in das Bild eingebaut. Das Ziel ist, die einzelnen Bilder so miteinander zu verschmelzen, dass möglichst keine sichtbaren Übergänge zwischen den verschiedenen Elementen entstehen.
Ziel der Aufgabe :
Das Projekt soll zeigen, dass verschiedene Photoshop-Techniken zur professionellen Bildkomposition eingesetzt werden können.
Besonders wichtig sind:
sauberes Freistellen der einzelnen Elemente
realistische Schatten und Lichtscheine
eine korrekte Ebenenreihenfolge
sinnvolle Benennung der Ebenen
Arbeiten mit Ebenenmasken statt Radieren
Verwendung verschiedener Ebenenmodi
Verwendung von Einstellungsebenen zur Farbanpassung
Verwendung von Schnittmasken
non-destruktives Arbeiten
Die Aufgabenstellung verlangt ausdrücklich, dass Veränderungen über Masken und neue Ebenen vorgenommen werden.

 Umsetzung:
Für die Umsetzung wurde zunächst der Hintergrund mit den Gebäuden von Tokyo vorbereitet. Anschließend wurde Godzilla freigestellt und passend zwischen den Gebäuden platziert.
Weitere Elemente wurden hinzugefügt und über Ebenen, Masken und Einstellungsebenen an die Umgebung angepasst.
Besonderes Augenmerk wurde auf folgende Punkte gelegt:
1. Freistellung
Die Objekte wurden sauber vom ursprünglichen Hintergrund getrennt.
2. Positionierung
Godzilla und die zusätzlichen Elemente wurden passend in die Tokyo-Szene integriert.
3. Schatten und Licht
Schatten und Lichtscheine wurden hinzugefügt, damit die Elemente realistischer in die Szene integriert wirken.
4. Farbkorrektur
Die Farben und Helligkeiten wurden mithilfe von Einstellungsebenen an die Umgebung angepasst.
5. Ebenen und Masken
Die Bearbeitung erfolgte non-destruktiv. Statt Bildbereiche direkt zu löschen, wurden Ebenenmasken verwendet.
6. Ebenenmodi
Unterschiedliche Ebenenmodi wurden eingesetzt, beispielsweise für Licht- oder Feuereffekte.
